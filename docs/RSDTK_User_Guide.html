01 Overview

RSDTK (Remote Sensing Data Toolkit) is a desktop application for batch converting satellite and airborne remote sensing data into analysis-ready formats. It handles the tedious work of merging single-band files, applying calibration and scaling factors, reprojecting swath data, and writing standardized GeoTIFF and ENVI outputs — all through a point-and-click interface.

RSDTK supports 14 sensor families with 30+ product types across three categories:

02 Getting Started

Installation

If you received the installer (RSDTK_v1.2_Setup.exe), simply run it and follow the prompts. RSDTK is fully self-contained — no Python or additional software is needed.

Data Preparation

Before processing, organize your data as downloaded from NASA EarthData or the relevant data provider. RSDTK supports two folder layouts:

📁 Subfolder Mode (Recommended)

One subfolder per granule, as downloaded from LP DAAC:

ASTER_Data/
├── AST_05_00304122020150510_20210222115129_26357/
│   ├── AST_05_..._SRE_TIR_B10.tif
│   ├── AST_05_..._SRE_TIR_B11.tif
│   └── ...
├── AST_05_00305142020150455_20210222115159_26490/
│   └── ...
📁 Flat Folder Mode

All files from multiple granules in a single folder — RSDTK will auto-group them by granule ID:

ASTER_Data/
├── AST_05_..._26357_SRE_TIR_B10.tif
├── AST_05_..._26357_SRE_TIR_B11.tif
├── AST_05_..._26490_SRE_TIR_B10.tif
└── ...

Quick Start

  1. Launch RSDTK — double-click the desktop shortcut or find it in the Start Menu.
  2. Select a sensor — click a sensor card from the left panel (e.g. "ASTER").
  3. Set options — choose the data version (V004/V003 for ASTER), product type, and output format.
  4. Choose folders — set your input folder (where the raw data lives) and optionally an output folder.
  5. Click "Process Data" — watch the log panel for progress. Output files appear in GeoTIFF/ and ENVI/ subfolders.

03 GUI Walkthrough

Sidebar

The dark sidebar on the left contains navigation buttons (Sensor Selection and Processing) and an Appearance toggle to switch between Dark, Light, and System themes. The sidebar remains dark in all themes for readability.

Sensor Selection Panel

Click any sensor card to select it. The card highlights in red and the view automatically switches to the Processing panel. Sensors are organized into three groups: Spaceborne Multispectral, Spaceborne Hyperspectral, and Airborne.

Processing Panel

The processing panel contains:

  • Input/Output folders — use Browse buttons to select. Output defaults to input/converted/.
  • Output Format — choose GeoTIFF, ENVI, or Both.
  • Overwrite — when checked (default), existing files are replaced. When unchecked, filenames auto-increment (_v2, _v3).
  • Sensor-specific options — product type, projection, resolution, band selection, etc.
  • Spatial Subset — optional bounding box (manual coordinates or shapefile/KML/GeoJSON).
  • Spectral Options — for hyperspectral sensors: every-Nth band, wavelength ranges, or match to another sensor's bands.
  • Processing Log — real-time output showing progress, warnings, and any errors.
  • Process Data / Cancel / Open File Location — start processing, cancel a running job, or open the output folder in Windows Explorer after processing completes.

04 Supported Sensors & Datasets

🏔️ ASTER — Advanced Spaceborne Thermal Emission and Reflection Radiometer

ASTER flies on NASA's Terra satellite (launched 1999) and captures data in 14 bands spanning VNIR (0.52–0.86 µm), SWIR (1.6–2.43 µm), and TIR (8.1–11.7 µm). NASA distributes ASTER data through the LP DAAC in two versions:

ℹ️ V004 vs V003

V004 (current) — individual GeoTIFF files per band, already map-projected. RSDTK merges them into multiband files and applies scaling factors.

V003 (legacy) — single HDF4 files containing all bands. RSDTK reads bands via pyhdf, applies scaling, and builds geolocation from tie-point arrays or sidecar metadata files (.aux.xml / .met).

✨ AST_07M — Merged Product

Exclusive to V003 processing. When you select AST_07M, RSDTK processes both VNIR and SWIR files individually, then matches pairs by acquisition timestamp, downsamples the VNIR from 15m to 30m via 2×2 block averaging, and creates a single 9-band reflectance cube. Pairs are matched by reading the SDS contents (not filenames) to correctly identify VNIR vs SWIR files.

⚠️ V003 Hemisphere Note

NASA's V003 .aux.xml metadata often incorrectly labels southern-hemisphere scenes as "Northern Hemisphere" in the WKT string. RSDTK derives the UTM hemisphere from the actual latitude of the tie-point arrays, not from the metadata WKT.

📋 QA Output Files (v1.1)

For V004 products, RSDTK now creates a separate QA multiband file alongside each science output, containing the QA_DataPlane and QA_DataPlane2 layers. For AST_09T, separate QA files are created for SurfaceRadiance and SkyIrradiance. QA files are named with a _QA suffix.

ℹ️ Reflectance / Emissivity Validity Masking (v1.1)

For AST_05 (emissivity) and AST_07 (reflectance), any pixels with scaled values outside the physically valid 0–1 range are automatically set to NaN in GeoTIFF output and 0 in ENVI output. These artifacts typically arise from failed atmospheric correction over clouds, shadows, or saturated pixels.

🛰️ Landsat — Collection 2 (All Missions)

RSDTK supports the full Landsat archive (Landsat 1–9) with auto-detection from MTL metadata. NASA/USGS distributes Collection 2 data as individual GeoTIFF bands via EarthExplorer or the USGS M2M API.

Level-1 (Top of Atmosphere)

L8/9 OLI/TIRS: VSWIR (B1–7,9) + TIR (B10–11) + Pan (B8) L7 ETM+: VSWIR (B1–5,7) + TIR (B6 VCID 1/2) + Pan (B8) L4/5 TM: VSWIR (B1–5,7) + TIR (B6) L1–5 MSS: 4 VSWIR bands (L1–3: B4–7, L4–5: B1–4)

RSDTK applies reflectance/radiance calibration from the MTL file and outputs separate VSWIR, TIR, and Panchromatic multiband files. The sensor is auto-detected — you can point at any L1TP/L1GT folder.

Level-2 (Surface Products)

L8/9: SR (B1–7) + ST (B10) + Ancillary (7 layers) L7 ETM+: SR (B1–5,7) + ST (B6) + Ancillary L4/5 TM: SR (B1–5,7) + ST (B6) + Ancillary

L2SP products are atmospherically corrected. RSDTK handles the ST_B10 vs ST_B6 naming difference automatically. No MSS Level-2 products exist.

ℹ️ Mixed L1/L2 Folders

If L1TP and L2SP files share the same folder, RSDTK's scene discovery automatically selects the correct MTL for the product you chose — L1TP for Level-1, L2SP for Level-2.

🛰️ Sentinel-2 L2A — Surface Reflectance

Sentinel-2A (2015) and Sentinel-2B (2017) from ESA's Copernicus programme carry the MSI (Multispectral Instrument) with 13 bands at 10m, 20m, and 60m resolution. L2A products are atmospherically corrected by the Sen2Cor processor.

Products

R10m: B02, B03, B04, B08 (Blue, Green, Red, NIR) R20m: B01–B07, B8A, B11, B12 (10 bands) SCL: Scene Classification Layer

NASA/ESA distributes Sentinel-2 as SAFE format folders. RSDTK reads the individual JP2/GeoTIFF bands from the .SAFE directory structure and merges them into multiband outputs at their native resolutions.

🛰️ Sentinel-3 — SLSTR, OLCI & Synergy

Sentinel-3A (2016) and S3B (2018) from ESA's Copernicus programme carry SLSTR (thermal/VNIR, 500m–1km) and OLCI (21-band VNIR, 300m). Data is distributed as .SEN3 folders of NetCDF files via Copernicus Data Space. Product type is auto-detected from the folder name.

SLSTR L1B RBT (Radiance / Brightness Temperature)

VNIR/SWIR: S1–S6 radiance (500m nadir) TIR: S7–S9 + F2 brightness temperature (1km) Fire: F1 brightness temperature (1km, separate grid)

Outputs three files per scene: VNIR/SWIR Radiance, TIR BT, and Fire BT. Reprojected from swath to geographic WGS-84 grid via KD-tree.

SLSTR L2 LST (Land Surface Temperature)

LST: Day/Night surface temperature (K) + uncertainty (1km)

OLCI L1B EFR (Full Resolution TOA Radiance)

Bands: Oa01–Oa21 (400–1020 nm, 300m)

21-band TOA radiance covering ocean colour, vegetation, and atmospheric channels.

Synergy L2 SYN (Surface Reflectance)

OLCI: 16 bands surface reflectance (Oa01–12, 16–18, 21) SLSTR: 5 bands surface reflectance (S1–3, 5–6 nadir)

Combined OLCI+SLSTR atmospherically corrected product on the 300m OLCI grid. O₂ absorption and water vapour bands (Oa13–15, 19–20) are excluded by ESA.

⚠️ Long Folder Names

Sentinel-3 .SEN3 folder names can exceed Windows path limits. Keep input directories short, or extract the .SEN3 folder contents into shorter-named directories.

🌡️ ECOSTRESS — ECOsystem Spaceborne Thermal Radiometer on Space Station

ECOSTRESS (2018, ISS) measures surface temperature and emissivity with 5 TIR bands (8–12.5 µm) at ~70m resolution. Data is available from LP DAAC.

L1CT — Terrain-Corrected Radiance

Format: Individual GeoTIFF bands Bands: 5 TIR radiance + cloud/water/QA masks Resolution: ~70m

RSDTK merges the individual radiance band GeoTIFFs into a single multiband file, similar to the ASTER V004 workflow.

L2 LSTE — Land Surface Temperature & Emissivity

Format: HDF5 (.h5) Products: LST, 5-band Emissivity, Emissivity WB, QA/Errors Reprojection: KD-tree swath → Geographic or UTM

L2 LSTE data is in swath format requiring reprojection. RSDTK uses KD-tree spatial interpolation with zero-initialization to avoid NaN propagation. Supports spatial subsetting via bounding box.

🌍 VIIRS — Visible Infrared Imaging Radiometer Suite

VIIRS flies on Suomi NPP (2011) and NOAA-20/JPSS-1 (2017), providing global daily coverage. Data is distributed by LAADS DAAC in HDF5/NetCDF format.

VNP02IMG — Imagery Resolution Bands

Bands: I01–I05 (5 bands, 375m) Geolocation: Separate VNP03IMG file required

VNP02MOD — Moderate Resolution Bands

Bands: M01–M16 (16 bands, 750m) Geolocation: Separate VNP03MOD file required

VNP21 — Land Surface Temperature & Emissivity

Products: LST, Emis_14/15/16, errors, QA, view angle Geolocation: Embedded in file
ℹ️ VIIRS Band Selection

VIIRS files can take ~15 minutes to process at full band count. Use the Bands dropdown to select subsets:

⚠️ Geolocation Files

VNP02IMG and VNP02MOD require matching VNP03IMG/VNP03MOD geolocation files in the same folder. VNP21 has embedded geolocation and doesn't need a separate file. RSDTK auto-detects the matching geo file.

🛰️ MODIS — Moderate Resolution Imaging Spectroradiometer

MODIS flies on both Terra (2000) and Aqua (2002). RSDTK supports gridded daily products in HDF-EOS2 format from LP DAAC. Output retains the native sinusoidal projection — reproject in ArcGIS Pro or QGIS as needed.

Surface Reflectance (MOD09GA / MYD09GA)

Bands: 1–7 (Red, NIR, Blue, Green, SWIR ×3) Resolution: 500m (2400 × 2400 per tile) Scale: 0.0001, fill = -28672

LST / Emissivity (MOD11A1 / MYD11A1)

LST: Day + Night surface temperature (K) Emissivity: Band 31 (11.03 µm) + Band 32 (12.02 µm) Resolution: 1km (1200 × 1200 per tile)
ℹ️ Sinusoidal Projection

MODIS data stays in its native sinusoidal projection to avoid resampling artifacts. The CRS is embedded in the GeoTIFF — ArcGIS Pro and QGIS will reproject on-the-fly for display.

🌈 EMIT L2A — Earth Surface Mineral Dust Source Investigation

EMIT (2022, ISS) is a hyperspectral VSWIR imaging spectrometer with 285 bands spanning 380–2500 nm at 60m resolution. L2A products contain atmospherically corrected surface reflectance. Data is in NetCDF4 format from LP DAAC.

Orthorectification

EMIT uses a GLT (Geometric Lookup Table) for orthorectification — significantly faster than KD-tree methods. The GLT maps each output pixel to its corresponding input swath position. RSDTK supports spatial subsetting by clipping the GLT window to a bounding box.

Bands: Up to 285 (good wavelengths filter available) Spectral options: Match to Landsat, Sentinel-2, ASTER, or MODIS bands Optional: RMSE uncertainty cube

📡 AIRS L1B — Atmospheric Infrared Sounder

AIRS (2002, Aqua satellite) is a hyperspectral infrared sounder with 2378 channels spanning 3.7–15.4 µm at ~13.5 km resolution. L1B products contain calibrated radiance in HDF-EOS format.

Channels: 2378 (ordered by ascending wavelength) Band names: Include both wavelength (µm) and wavenumber (cm⁻¹) Reprojection: KD-tree (135 × 90 pixel swath)

✈️ MASTER — MODIS/ASTER Airborne Simulator

MASTER is a JPL airborne instrument with 50 bands spanning VNIR through TIR (0.46–12.8 µm). It flies on NASA's ER-2 and other aircraft for calibration/validation campaigns.

L1B — Calibrated Radiance

Format: HDF4 Bands: 50 (VSWIR + TIR) Option: Convert VSWIR to TOA Reflectance Resolution: Configurable (default 50m)

L2 — Emissivity & LST

Format: HDF5 Products: Emissivity, Land Surface Temperature, QA

✈️ HyTES — Hyperspectral Thermal Emission Spectrometer

HyTES is a JPL airborne TIR hyperspectral sensor with 256 bands spanning 7.5–12 µm. It provides very high spectral resolution thermal data for mineral mapping and volcanic monitoring.

L1 — Calibrated Radiance

Bands: 256 TIR channels Resolution: Configurable (native ~1.7m)

L2 — Emissivity & LST

Products: Emissivity (5 bands), LST, PC Emissivity (256 bands, optional)
⚠️ Large File Sizes

HyTES L1 data at native resolution with 256 bands can produce very large files (7+ GB). Use the Resolution field to downsample (e.g. 20m) and/or spectral subsetting to reduce output size.

✈️ AVIRIS-3/5 — Airborne Visible/Infrared Imaging Spectrometer

AVIRIS-3 (284 bands, 390–2500 nm) and AVIRIS-5 (424 bands) are JPL's latest airborne VSWIR hyperspectral sensors. Both are auto-detected from the AV3/AV5 filename prefix.

L1B Calibrated Radiance

Format: NetCDF4 with GLT orthorectification Resolution: Configurable (native varies by altitude) Water vapor: Auto-excluded (1334–1440 nm, 1788–1980 nm)

L2A Surface Reflectance (from EarthData/ORNL DAAC)

Format: Orthorectified NetCDF4 on UTM grid Ancillary: AOT + Water Vapor (separate 2-band file) Spatial subset: Supported (lon/lat → UTM crop)

L2A files are already orthorectified — no GLT needed. RSDTK reads the reflectance, wavelength, and FWHM from NetCDF groups and writes analysis-ready outputs.

✈️ AVIRIS-NG & Classic AVIRIS

AVIRIS-NG (425 bands, 5 nm spacing, 3.7m) and Classic AVIRIS (224 bands, 10 nm spacing, 15.7m) are earlier-generation JPL spectrometers. Both are distributed as orthorectified ENVI binary files.

AVIRIS-NG

L1B: ang{date}t{time}_rdn_*_img (radiance) L2: ang{date}t{time}_corr_*_img (reflectance) Projection: UTM with rotation (handled via affine transform)

Classic AVIRIS

L1B: f{date}t{nn}p{nn}r{nn}rdn_g_*ort_img (radiance) L2: f{date}t{nn}p{nn}r{nn}_rfl (reflectance)

05 Shared Features

Spatial Subsetting (Bounding Box)

Available for: ECOSTRESS, EMIT, AVIRIS-3/5 (L1B and L2A), AVIRIS-NG, Classic AVIRIS, Sentinel-3, MASTER, HyTES, AIRS. Enter coordinates manually (min/max lat/lon) or browse to a shapefile, KML, or GeoJSON file. The bounding box clips the output grid before processing, reducing both processing time and file size.

Spectral Subsetting

Available for: EMIT, AVIRIS-3/5 (L1B and L2A), AVIRIS-NG, Classic AVIRIS, MASTER L1B, HyTES L1/L2, AIRS. Options include:

ModeDescription
Every NthKeep every Nth band (e.g. every 5th for quick previews)
Custom RangeSpecify wavelength ranges (e.g. 450-900,2000-2400 nm)
RegionVNIR only, SWIR only, VIS, NIR, or Full
Match SensorResample to Landsat 8/9, Sentinel-2, ASTER, or MODIS band positions

Overwrite Control

The "Overwrite existing files" checkbox (default: ON) controls whether existing output files are replaced or auto-incremented with _v2, _v3 suffixes. This applies to all sensors.

Reprojection

Swath-format sensors (ECOSTRESS, VIIRS, Sentinel-3 SLSTR/OLCI/Synergy, MASTER, HyTES, AIRS) are reprojected to Geographic (EPSG:4326) using KD-tree nearest-neighbor interpolation. MODIS data stays in native sinusoidal projection. Landsat, Sentinel-2, ASTER, AVIRIS-3/5, and AVIRIS-NG/Classic are already on regular grids and need no reprojection.

06 Output Formats

GeoTIFF

Multiband float32 with DEFLATE compression (predictor=2, zlevel=6). Includes CRS, geotransform, band descriptions, and NaN nodata. Compatible with ArcGIS Pro, QGIS, Google Earth Engine, and all standard GIS software.

ENVI

BSQ (Band Sequential) format with a companion .hdr header file. Includes wavelength metadata in micrometers (TIR) or nanometers (VSWIR), band names, and coordinate system information. Nodata value is -9999 (ENVI does not support NaN). Optimized for ENVI software's spectral analysis tools.

ℹ️ Output Organization

RSDTK automatically organizes output files into GeoTIFF/ and ENVI/ subfolders within the output directory. For AST_09T, Surface Radiance and Sky Irradiance files are further separated into their own subfolders.

07 Troubleshooting

🔴 "No files found" error

Make sure you're pointing to the correct folder and have selected the right sensor/product type. For ASTER, check that V003/V004 toggle matches your data format (.hdf vs .tif).

🔴 VIIRS "No matching geolocation file"

VNP02IMG/VNP02MOD files require matching VNP03IMG/VNP03MOD geolocation files in the same input folder. Download both from LAADS DAAC.

🔴 ENVI header read error

If ENVI can't read a header file, check for any stale .aux.xml files alongside the .dat file and delete them — these are spurious files created by rasterio that can confuse ENVI.

⚠️ Processing is very slow

For VIIRS: use the band selection presets to process only the bands you need. For HyTES/MASTER: increase the output resolution (e.g. 20m instead of native). For AVIRIS-3: use the resolution field and/or spectral subsetting.

⚠️ Output file in wrong location

For ASTER V003 southern hemisphere scenes: the output should now be correctly placed in UTM South. If using very old output files, delete them and reprocess — earlier versions had a hemisphere bug in the NASA metadata.

ℹ️ Reporting Issues

Copy the full error text from the Processing Log panel (use the scroll bar to see the complete traceback) and share it when reporting issues. The log captures all converter output and Python exceptions.
